# Использование J.A.R.V.I.S.

## Команда `jarvis`

Первое, что стоит сделать после установки: **`jarvis selftest`** — прогоняет все 29 mac_* инструментов в режиме чтения и
печатает таблицу «✔ работает / ⚠ нет прав (какую панель открыть) / ✖ сломано». `jarvis selftest --fix` открывает панели сам.
Затем **`jarvis brain import`** — JARVIS познакомится с вашими контактами и проектами (с подтверждением).

| Команда | Что делает |
|---|---|
| `jarvis` | голосовой TUI Hermes с профилем JARVIS (wake word + Ctrl+B) |
| `jarvis chat` | классический CLI (`hermes chat`) |
| `jarvis ask "вопрос"` | один вопрос — один ответ, без интерактива (удобно в скриптах/Shortcuts) |
| `jarvis hud` / `hud stop` / `hud log` | HUD в браузере |
| `jarvis gateway` / `gateway stop` | мессенджеры + OpenAI-совместимый API (`:8642`) |
| `jarvis up` | gateway + HUD + TUI одной командой |
| `jarvis status` | состояние компонентов |
| `jarvis brief` | брифинг прямо сейчас |
| `jarvis brain [stats\|review\|export\|log\|backup\|sql]` | база знаний: статистика, ревизия сейчас, выгрузка в Markdown, журнал изменений |
| `jarvis doctor` | `hermes doctor` + проверка плагинов |
| `jarvis update` | обновить Hermes и плагины |
| `jarvis perms` | открыть панели разрешений macOS |
| `jarvis selftest [--fix]` | проверить все mac_* инструменты на этом Mac (без LLM); `--fix` открывает панели недостающих прав |
| `jarvis brain import` | первичный импорт контактов/проектов в базу знаний |
| `jarvis heartbeat` | одна тихая проверка по `HEARTBEAT.md` (то, что cron делает каждые 45 мин) |
| `jarvis update [--check\|--status\|--rollback\|--channel\|--auto]` | автообновление с GitHub (см. docs/APP.md) |
| `jarvis app [build\|quit]` | приложение строки меню JARVIS.app |
| `jarvis version` | версии JARVIS и Hermes |
| `jarvis config` | открыть config.yaml |
| `jarvis logs` | хвост логов |
| `jarvis <любая команда hermes>` | прозрачно передаётся в `hermes` (`jarvis cron list`, `jarvis skills list`…) |

## Проактивность без болтовни

| Механизм | Что делает | Стоимость |
|---|---|---|
| **Watchdog** (jarvis-core) | батарея, встречи за 10 минут **со справкой из базы знаний** на HUD, синхронизация с Focus macOS | 0 вызовов LLM |
| **Heartbeat** (`jarvis heartbeat`, cron каждые 45 мин) | читает `~/.hermes/jarvis/HEARTBEAT.md`, проверяет пункты, отвечает `NO_REPLY`, если всё спокойно; помнит, о чём уже предупреждал | 1 короткий вызов |
| **Утренний verify** | 1 сомнительный факт из базы уточняется в конце брифинга | в составе брифинга |

`HEARTBEAT.md` — обычный список; правьте руками или «JARVIS, добавь в heartbeat: напоминать пить воду после 15:00».
Отключить heartbeat: `hermes cron remove <id>` или `JARVIS_HEARTBEAT=0 bash ~/.hermes/jarvis/setup_cron.sh` до установки.

### Focus macOS ↔ режим JARVIS
Включили «Не беспокоить»/«Работа» — JARVIS сам переходит в `focus` (только срочное); «Сон» → `night`; выключили → `normal`.
Читается `~/Library/DoNotDisturb/DB` (терминалу может понадобиться «Полный доступ к диску»; если доступа нет — просто ничего
не происходит). Управлять Focus *из* JARVIS: создайте Быструю команду «JARVIS Focus Работа» с действием «Установить фокус» —
`mac_focus set` вызывает её.

## Режимы (`jarvis_mode`)

| Режим | Поведение агента | Побочные эффекты |
|---|---|---|
| `normal` | обычный | — |
| `focus` | минимум слов, никакой инициативы | Shortcut «JARVIS Mode focus» (или «JARVIS Focus On»), если создан — например, включает «Не беспокоить» |
| `night` | тихо, кратко | Shortcut «JARVIS Mode night», если создан |
| `presentation` | не трогает окна/звук/уведомления | Shortcut «JARVIS Mode presentation», если создан |

Режим сохраняется между сессиями и подмешивается в контекст каждого хода.

## HUD

HUD — рабочий стол JARVIS в браузере (`jarvis hud` → http://127.0.0.1:8765). Три колонки на **реальных данных**:

| Виджет | Откуда данные | Что можно делать |
|---|---|---|
| **Сегодня** | Calendar.app (AppleScript, обновляется раз в 2 мин) | «Все события» — спросить JARVIS про сегодня/завтра |
| **Знания** | `brain.db` плагина jarvis-brain | открыть базу знаний, поиск |
| **Система** | `pmset` (батарея), Focus macOS, `config.yaml` (модель), `install.json` (версия) | переключить режим фокуса JARVIS |
| **Таймеры** | общий `state.json` с `jarvis_timer` | добавить/отменить таймер прямо в HUD; срабатывает даже без запущенного агента |

Если Календарь показывает «нет доступа» — Системные настройки → Конфиденциальность и безопасность → Автоматизация → разрешите Terminal (или JARVIS) управлять Calendar.

| Клавиша | Действие |
|---|---|
| **Пробел (удерживать)** / клик по сфере | говорить (Web Speech API браузера; локальный Whisper — в голосовом режиме TUI) |
| **Enter** | отправить текст |
| **K** | база знаний |
| **A** | лента активности агента (tool calls, панели, фон) |
| **T** | озвучивать ответы голосом браузера |
| **H** | спрятать/показать боковые колонки (только сфера и диалог) |
| **?** | подсказка по клавишам |
| **Esc** | очистить диалог и закрыть центральные панели |

Deep links: `/#brain`, `/#activity`. Для скриншотов и разработки: `python3 hud/server.py --demo` (виджеты с демо-данными).
- Панели: агент вызывает `jarvis_hud` (kind: text/markdown/image/video/web/chart; position: left/center/right; ttl).
- Лента слева — все tool calls в реальном времени (в т.ч. из Telegram/Discord через gateway-хук).
- Открыть с телефона в той же сети: запустите HUD с `JARVIS_HUD_HOST=0.0.0.0` (только в доверенной сети!).

## Cron-задачи JARVIS (создаются установщиком)

```bash
hermes cron list
```
| Имя | Расписание | Что делает |
|---|---|---|
| JARVIS: утренний брифинг | 08:00 | погода, календарь, напоминания, батарея |
| JARVIS: вечерний итог | 21:00 | что сделано, что перенести, завтра |
| JARVIS: ночная ревизия базы знаний | 03:30 | уборка, дневник дня, слияние дубликатов, таксономия, карточки, отчёт (см. docs/BRAIN.md) |
| JARVIS: обслуживание памяти | вс 20:00 | чистка MEMORY.md / USER.md, перенос устойчивых фактов в базу знаний |
| JARVIS: heartbeat | каждые 45 мин | чек-лист `~/.hermes/jarvis/HEARTBEAT.md`; ответ `NO_REPLY` = ничего не отправляется |

Контроль батареи и напоминания о встречах делает **watchdog** внутри `jarvis-core` — локально, без вызовов LLM
(настройки `battery_threshold`, `watch_calendar`).

Доставка результатов — туда, откуда создана задача (CLI → лог; из Telegram → в Telegram).
Изменить: `hermes cron edit <id> …`, удалить: `hermes cron remove <id>`.

## Личность

`~/.hermes/SOUL.md` — отредактируйте, чтобы поменять характер/обращение/язык.
`plugins.entries.jarvis-core.settings.user_name` — как JARVIS вас называет.
`/personality <preset>` — временный оверлей на сессию.
