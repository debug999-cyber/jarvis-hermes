# Управление Mac

## When to Use
Любая просьба, затрагивающая компьютер: приложения, звук, экран, окна, файлы, музыка, календарь,
заметки, напоминания, буфер обмена, питание.

## Decision table
| Просьба | Инструмент |
|---|---|
| открой/закрой приложение | `mac_app` |
| открой сайт / файл / папку | `mac_open` |
| найди файл | `mac_spotlight` → потом `mac_finder reveal` |
| громче/тише/звук | `mac_volume` |
| ярче/темнее | `mac_brightness` |
| тёмная тема | `mac_dark_mode` |
| заблокируй / усыпи / выключи | `mac_power` (restart/shutdown — только после подтверждения!) |
| музыка | `mac_media` |
| что на экране? | `mac_screenshot` → `vision_analyze(path)` |
| что видит камера? | `mac_camera_snap` → `vision_analyze(path)` |
| планы / встречи | `mac_calendar` |
| напомни | `mac_reminders` (с датой) или `jarvis_timer` (короткие интервалы) |
| запиши / заметка | `mac_notes` |
| скопируй / вставь | `mac_clipboard` |
| напечатай / нажми | `mac_type` |
| окно влево/вправо/на весь экран | `mac_window` |
| быстрая команда | `mac_shortcut` |
| всё остальное про Mac | `terminal` (безопасные команды) или `mac_applescript` (если включён) |

## Procedure
1. Выбери самый специализированный инструмент из таблицы. `terminal` — только если ничего не подходит.
2. Для необратимых действий (выключение, очистка корзины, удаление файлов) — сначала `clarify`/переспроси.
3. После действия отвечай коротко: «Готово, Safari открыт», без пересказа JSON.
4. Если инструмент вернул `error` про Accessibility/Automation — объясни пользователю в одну фразу, где включить разрешение:
   *Системные настройки → Конфиденциальность и безопасность → Универсальный доступ / Автоматизация / Запись экрана.*

## Pitfalls
- Имена приложений — как в /Applications (например, «Visual Studio Code», «Google Chrome», «Музыка»/«Music»).
- `mac_type` печатает в АКТИВНОЕ окно — сначала `mac_app activate` нужного приложения.
- Скриншоты требуют разрешения «Запись экрана» для процесса-терминала.
- Не вызывай `mac_say`, если TTS Hermes уже включён — будет двойной голос.

## Verification
Инструмент вернул `"success": true`; при необходимости подтверди результат (`mac_app is_running`, `mac_volume get`).
