# AGENTS.md — инструкции JARVIS для работы в этой директории

Этот файл Hermes подхватывает автоматически, когда рабочая директория — репозиторий jarvis-hermes.

- Код плагинов: только stdlib, Python 3.11+, обработчики инструментов никогда не бросают исключения.
- Перед изменением схем инструментов прочитай `docs/DEVELOPMENT.md`.
- После правок запускай `python3 -m pytest tests -q`.
- Не трогай `~/.hermes/config.yaml` напрямую — правь `config/config.jarvis.yaml` и используй `scripts/merge_config.py`.
- Документация — на русском, идентификаторы — на английском.
